# Clawd Band

The Claude desktop app's animated Clawd, living in a band above the prompt box with your session's stats and a sky that changes through the day.

Version **1.7.1**. The full feature list is in [FEATURES.txt](FEATURES.txt).

## What's on the band

**Left: the clock and stats.**

- **Clock**: a pixel desk clock. It glows blue at night.
- **5H / 7D**: your 5-hour and 7-day usage limits, as glowing bars. The bar and its percent change colour as the limit fills:

  | Used | Colour |
  | --- | --- |
  | 0–40% | green |
  | 40–70% | ink |
  | 70–90% | yellow |
  | 90–95% | red |
  | 95–100% | red, pulsing |
- **SESSION**: this session's cost.
- **CTX**: how full the context window is, split by category: messages, system tools, MCP tools, other and buffer.
- **HIT / TOK/S**: the last reply's prompt cache hit rate and output speed.
- **CACHE**: minutes before the prompt cache goes cold. Frost creeps over it in the last 10 minutes.
- **STATUS**: what Claude is doing right now, with the turn's elapsed time.

Stats are read every 2 seconds, during a turn too. When a turn ends, CACHE is back at 60 with a fire glow, or a thaw if it was frosting over. Chips keep a fixed width, so the band doesn't jump around.

**Right: the sky and Clawd.**

Clawd changes form with what Claude is doing: typing for edits, a computer for commands, searching, fetching, delegating, asking and more. A turn ends with a little celebration (Done, or BigDone for long turns) or Sad if it was interrupted. While idle, Clawd looks around now and then. At night it sleeps.

## The day and night

From 05:30 to 23:15 the day runs through eight periods, each with its own tint, idle word and sky. The sun crosses one arc from dawn to dusk, fuzzy clouds drift through, and each period has a visitor:

| Period | Starts | Idle word | Visitor |
| --- | --- | --- | --- |
| Dawn | 05:30 | Stirring | hot-air balloon rising |
| Morning | 07:44 | Brewing | paper plane looping |
| Late morning | 09:57 | Ready | kite on a string Clawd holds |
| Midday | 12:10 | Lunching | plane contrail and a monarch butterfly |
| Afternoon | 14:23 | Lounging | dandelion seeds drifting |
| Golden hour | 16:36 | Basking | a V of geese heading home |
| Dusk | 18:49 | Unwinding | sky lanterns rising |
| Evening | 21:02 | Drowsy | full moon, stars and the first z's |

At night (23:15–05:30) the band goes dark whatever your theme. A crescent moon glows, stars twinkle, z's drift up from a sleeping Clawd, and comets with dusty tails glide across on random paths.

## Commands

- Cold-send guard: a message onto a cold cache with over 50k tokens of context is stopped once with what the re-write will cost; send it again to pay it.
- `/ctxdebug`: temporary. It prints what the session reports about context.

## Install

From this repository's marketplace:

```bash
claude plugin install clawd-band@my-mods
```

Restart Claude Code to load it. The band draws in the desktop app; in a terminal you get a small block-character Clawd instead.

## Development

- `hooks/register.tsx`: the hooks. They track state, play forms and render the band.
- `hooks/design.ts`: the drawings. That's the stats, the day skies and the night scene.
- `hooks/pixel-clock.ts`: the clock.
- `hooks/clawd-frames.ts`: Clawd's animated forms, generated by `tools/gen.py` from `tools/sprites.json`.

Run the tests with:

```bash
claude plugin test clawd-band
```
